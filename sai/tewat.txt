LoadRunner Enterprise
LoadRunner Enterprise
LoadRunner Enterprise (LRE) is T-Mobile's enterprise-grade performance testing platform for creating, scheduling, and running load tests at scale. It supports script creation with VuGen, test execution with distributed load generators, and results analysis.

Key resources:

LoadRunner Enterprise - Main Documentation

Getting Started with LRE

How to get access:

Set Up for New User — includes creating your LRE account and installing required software (VuGen, Analysis)

Raise an LRE support ticket here: LRES - General Help

For execution permission when your user is already created, submit the LRES - Enable Execution request. This form is required for users to request a daily window to run performance test(s).
